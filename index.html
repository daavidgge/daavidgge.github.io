Comment cela fonctionne

Un assistant sur votre ordinateur.

01 / ORGANISER

Voir les priorités

L’intégration à l’API officielle Google Gmail synchronise les messages. L’assistant les classe, distingue les informations utiles des publicités et présente une synthèse des communications importantes.

02 / PRÉPARER

Écrire avec votre style

Ollama exécute le modèle local Qwen. Après activation, l’assistant peut préparer une réponse pour une vraie demande professionnelle, à partir d’un profil d’écriture validé. Il signale les informations à compléter.

03 / MAÎTRISER

Garder la décision

Les publicités peuvent être traitées en groupe après aperçu et confirmation. L’envoi d’un email exige toujours une action manuelle et une confirmation dédiée. Les règles permanentes demandent une autorisation explicite.

Usage personnel

Votre boîte reste privée.

L’application et son cache fonctionnent localement. Google fournit l’accès autorisé à Gmail ; Ollama réalise les traitements IA sur le PC. Aucun abonnement IA ni clé OpenAI n’est nécessaire pour ce mode local.

Les correspondances personnelles exclues ne servent pas à personnaliser le style professionnel. Le profil reste consultable, modifiable et soumis à validation.
